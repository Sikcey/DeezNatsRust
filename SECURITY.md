# Security reporting

ARL cookies grant access to a Deezer account. Treat them as credentials. Never
include them, session files, browser profiles or full authenticated responses in
issues, screenshots or logs.

For a vulnerability involving credentials, session storage, downloads or native
code, use GitHub private vulnerability reporting if enabled on the repository.
Otherwise contact a maintainer privately through their GitHub profile before
sharing sensitive details. Public issues are suitable for non-sensitive bugs.
