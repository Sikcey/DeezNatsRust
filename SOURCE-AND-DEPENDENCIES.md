# Source and dependencies

DeezNats Rust and DeezNats Connect are distributed under AGPL-3.0. See LICENSE
and NOTICE.md for the application license and third-party notices.

The application source, build instructions, and pinned Rust dependencies are
available in the project repository below. The bundled engine is based on the
[v0.1.6 source archive](https://github.com/Sikcey/DeezNatsRust/releases/download/v0.1.6/DeezNats-Source.zip),
which includes its pinned Go dependencies and notices, with the repository's
`patches/deezer-playback-recovery.patch` applied. See
`docs/DEEZER-PLAYBACK-RECOVERY.md` for build and test instructions.

Project repositories:

- https://github.com/Sikcey/DeezNatsRust

User profiles, credentials, downloaded media, and private development files are
not included in the repository.
